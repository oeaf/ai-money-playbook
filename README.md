## 📁 仓库结构

```
playbooks/   # AI 搞钱实战手册（核心资产）：提示词 + 流程 + 案例 + 复盘
cases/       # 真实案例拆解：注明来源、数据与时间，不编造数字
tools/       # AI 工具导航：分类 + 免费/付费 + 一句话点评，只列链接
books/       # 书单：只列书名与链接，不上传全文（版权红线）
weekly/      # 周更新学习笔记：保持这个仓库"活着"的证据
```

- 📌 当前收录：**3** 篇 playbook · **1** 篇案例拆解 · 工具导航持续补充中
- 🔄 更新节奏：每周至少 1 篇 playbook + 1 篇 weekly 笔记（少而活，胜过多而死）
