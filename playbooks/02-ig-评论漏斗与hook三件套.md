# Playbook 02：IG 评论漏斗与 Hook 三件套

- 记录日期：2026-10-07 / 2026-10-08
- 适用场景：Instagram Reels / 轮播，AI 赚钱方向
- 真实结果：21 篇 IG 爆款逐条拆解（养号期实测浏览记录）；核心结论——**评论本身就是算法燃料**，漏斗设计 = 获客 + 加权一举两得

## 三件套之一：评论关键词漏斗

结构：开头指令 + 利益承诺 → 中间"海量资源库"制造 FOMO → 结尾关键词自动私信交付。

- 实测案例：gptprompts.ai（92.1 万粉）帖 Hook `"Comment "CHATGPT" and I'll send you the 1000+ prompts."`——每条 "CHATGPT" 评论都在给帖子加权；该账号反复复用同一模板，说明是 ROI 稳定的固定打法。
- 要点：交付物直接标"X 百/X 千"量级（"大"本身就是 FOMO 钩子）；评论关键词选**最短的英文大写词**（CHATGPT / CODE 类），降低输入成本。
- 系列化放大：同一作者两条爆款 Reels（8.3 万 / 4.4 万播放）收口到**同一个**评论关键词，让爆款互相导流而不是各自为战。

## 三件套之二：Hook 公式库（按场景选）

| 场景 | 公式 | 实测案例 |
|---|---|---|
| 工具清单 | 命令式"占便宜"：`Steal The Top [数字] AI Tools for Making 💰` | shedoesai，2222 赞；不讲道理直接给利益 |
| 清单收藏 | `SAVE these [数字] ideas` + 编号轮播 + 文末评论漏斗收尾 | alimirza2k，5197 赞 / 981 评论 |
| 人物案例 | `别人还在 X，TA 已经 Y` 对比 + 年龄/身份反差 + 媒体出处背书 | moretify（中文），赞粉比 0.58% 本轮最高 |
| 反 hype | `I went down the rabbit hole… Most of it? Didn't work.` 试错叙事 + 证伪 + 唯一推荐 + 诚实锚点 | swarali.ai，1909 赞；评论区是真实长讨论 |
| 认知冲突 | 低端载体 × 离谱数字（"智障短片=月收8位数"）+ 反问收束不给结论 | fetchwithcao，4360 赞 |

## 三件套之三：结尾评论引导（三选一，不混用）

1. **开放提问**：引真实讨论（如 `"Which side hustle should I test next?"`）——真实长评论的算法质量高于关键词刷屏。
2. **投票式提问**：`"Which one would you try first?"`——"选一个"比"写一句"门槛低得多。
3. **评论漏斗**：关键词收口（见上）。

另：清单类标题加年份/时间限定词（`…in 2026`）制造时效；"截图诱饵 + 这个周末就能干"的紧迫感框架好用，但清单条目必须具体可执行（带载体和数字），避免"70 个点子"式泛清单。

## 避坑

- 看爆款先翻评论区：单调关键词刷屏的 ≠ 真爆款；粉丝多互动弱的（如 16 万粉 383 赞）说明标题大交付泛。
- IG 不带 TikTok 水印、不发低清视频（降权）；正文不堆外链。
